# Pima Diabetes Analysis

## Project Overview
Exploratory Data Analysis of the Pima Indians Diabetes Dataset using Python and Pandas.

## Tools Used
- Python
- Pandas
- Kaggle Notebook

## Analysis Performed
- Dataset exploration
- Statistical analysis
- Comparison between diabetic and non-diabetic patients

## Findings
- Diabetic patients had higher average BMI.
- Diabetic patients had higher average Glucose levels.
- Diabetic patients had higher average age.
